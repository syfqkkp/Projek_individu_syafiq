## Tentang Aplikasi

**MyTodo** adalah aplikasi todo list berbasis web untuk membantu mahasiswa mengatur tugas kuliah dan kegiatan pribadi dalam satu tempat. Tugas dibagi menjadi dua kategori, yaitu **Learning** (tugas kuliah) dan **Personal** (kegiatan pribadi). Selain daftar tugas, aplikasi menyediakan kalender dan fitur jam. Tampilannya modern, minimalis, bertema gelap, dan responsif (ponsel dan desktop).

Aplikasi dibangun tanpa framework, hanya dengan HTML5, CSS3, dan JavaScript murni. Desain UI/UX dibuat di Figma.

## Fitur Utama

- **Manajemen tugas**: tambah, hapus, dan tandai tugas sebagai selesai.
- **Kategori**: tampilkan tugas berdasarkan kategori Learning dan Personal.
- **Kalender**: lihat tugas berdasarkan tanggal.
- **Pencarian**: kolom pencarian yang langsung memfilter daftar tugas.
- **Detail tugas**: checklist dan catatan untuk tiap tugas.
- **Jam**: jam digital, alarm, dan timer belajar.
- **Responsif**: navigasi bawah pada ponsel, sidebar pada desktop.

## Cara Menjalankan

1. Clone atau unduh repositori ini.
   ```bash
   git clone <url-repositori>
   ```
2. Buka folder proyek.
3. Buka berkas `index.html` dengan browser modern (Chrome, Edge, Firefox, dll.) dengan klik dua kali atau klik kanan lalu *Open with*.
4. Alternatif: gunakan ekstensi **Live Server** di VS Code (klik kanan `index.html` lalu *Open with Live Server*).

Tidak perlu instalasi tambahan karena tidak ada dependensi atau proses build.
